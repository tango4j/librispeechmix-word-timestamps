# Data provenance and terms

The Apache-2.0 [`LICENSE`](LICENSE) covers the original software and documentation in this repository. It does **not** replace the terms of upstream datasets.

The released JSONL files are mechanically derived from:

1. [NaoyukiKanda/LibriSpeechMix](https://github.com/NaoyukiKanda/LibriSpeechMix), whose repository is MIT licensed and notes that the original LibriSpeech corpus is distributed under CC BY 4.0.
2. [CorentinJ/librispeech-alignments](https://github.com/CorentinJ/librispeech-alignments), which supplies Montreal Forced Aligner output but does not include an explicit standalone license file at the pinned revision.
3. [LibriSpeech](https://www.openslr.org/12), distributed under CC BY 4.0.

No audio is included. This project asserts no new exclusive rights over upstream source identifiers, transcripts, mixture metadata, or forced-alignment facts. Users should review and comply with the upstream terms and provide the citations requested in the main README.
